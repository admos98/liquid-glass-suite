Install

# Claude Code
/plugin marketplace add admos98/liquid-glass-suite
/plugin install liquid-glass-suite@admos98-skills

# Generic Agent Skills CLI — installs one entry carrying the whole suite
npx skills add admos98/liquid-glass-suite

Keep the suite intact. Each skills/<name> folder references ../../shared/…, so copying one folder alone breaks it. The generic CLI installs the suite as a single liquid-glass-suite skill for exactly that reason; it routes to the four skills inside the installation.

Liquid Glass is refraction, not blur

The backdrop bends near the boundary while the centre stays readable. backdrop-filter: blur() alone is frosted glass — a different material, and what most “liquid glass” snippets actually ship. The suite ships a universal blur() saturate() fallback, a conservatively gated Chromium SVG-backdrop lens, and an explicit-texture WebGL2 path that cannot read arbitrary DOM.

Verification, and its limits

  • 17 package tests, 11 Playwright browser tests, offline showcase build check, strict plugin manifest validation.
  • Every Apple signature quoted in the native skill was checked against Apple’s own DocC JSON.
  • Native Apple samples were not compiled — no Apple hardware was used, and no native-runtime pass is claimed.
  • Playwright Chromium is not a real iPhone. One physical-device run is recorded, with iOS/Safari versions unrecorded.
  • Apple publishes no numeric Liquid Glass specification. Every number in the suite is tagged apple-hig, community, figma or measured.
